🚀 Overview

The Student Performance Analytics System is a Python-based data analysis project designed to transform student records into meaningful academic insights.

Using a CSV dataset, the system processes subject-wise marks, calculates performance metrics, evaluates grades, and helps identify top-performing students.

🎯 The Goal: Make student performance analysis simple, structured, and data-driven.

---

✨ Key Features

- 📂 Student Data Management — Load student records from a CSV dataset.
- 🧮 Marks Analysis — Calculate total and average marks.
- 🎓 Grade Evaluation — Assign grades using predefined criteria.
- ✅ Result Classification — Determine pass/fail status.
- 🏆 Top Performers — Identify the top 3 students.
- 📊 Class Insights — Calculate the overall class average.
- 🔍 Subject Analysis — Identify the best-performing subject.
- 📉 Performance Comparison — Compare the highest and lowest student averages.

⚙️ How It Works

📥 1. Load Student Data

The program reads student records from "students.csv" and prepares the dataset for analysis.

🧮 2. Process Student Marks

Subject-wise marks are processed to calculate each student's total and average marks.

🎓 3. Evaluate Academic Performance

The program applies predefined grading criteria and evaluates student results.

📊 4. Analyze Class Performance

The system calculates the overall class average and compares student performance.

🏆 5. Identify Top Performers

The program identifies the top 3 students and highlights useful performance insights.
