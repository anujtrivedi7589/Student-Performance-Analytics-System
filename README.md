# 📊 Student Performance Analytics System

Control and analyze student results using Python!
Turn your raw marks into smart analytics, just like magic.

### 🚀 Overview
This project uses *Python, Pandas and NumPy* to analyze student performance in real-time. By reading student data, it tracks the marks and performs various analytics operations like total, average, grade and topper detection.

### ✨ Features
- 📚 Real-time CSV data tracking
- 🧮 Total and Average calculation
- 🖱️ Automatic Grade assignment
- 📜 Pass / Fail detection
- 📊 Subject-wise average analysis
- 🏆 Top performer detection
- ⌨️ Clean console output

### 🛠️ Tech Stack
- Python
- Pandas
- NumPy

### 🧩 How It Works
1. Loads student data from CSV
2. Calculates total and average marks
3. Assigns grade based on average
4. Analyzes class performance
5. Displays subject toppers and analytics

### 📁 Project Structure
main.py - Main file to run the analytics system
functions.py - Contains calculation functions
students.csv - Student dataset file
README.md - Project documentation
### ▶️ Getting Started

1.  Install Dependencies
    pip install pandas numpy
2.  Run the Project
    python main.py
### 🎮 Controls
- 👉 Run `python main.py` - Start Analytics
- ⛔ Ctrl + C - Exit System
