<h1 align="center">📊 Student Performance Analytics System</h1>

<p align="center">
  Analyze student academic performance effortlessly using Python! <br>
  Turn your raw CSV marks into smart insights, grades, and topper lists.
</p>

<hr>

<h2>🚀 Overview</h2>
<p>
This project uses <b>Python, Pandas and NumPy</b> to analyze student performance in real-time.
By reading student data from a CSV file, it calculates total, average, grades and generates performance analytics automatically.
</p>

<h2>✨ Features</h2>
<ul>
  <li>📚 Automatic CSV data loading</li>
  <li>🧮 Total, Average & Grade calculation</li>
  <li>🎯 Pass/Fail detection</li>
  <li>📈 Class average, Highest & Lowest marks</li>
  <li>📊 Subject-wise performance analysis</li>
  <li>🏆 Top 3 performers list</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
  <li><b>Python</b></li>
  <li>Pandas</li>
  <li>NumPy</li>
</ul>

<h2>🧩 How It Works</h2>
<ol>
  <li>Reads student data from students.csv</li>
  <li>Calculates total marks using functions</li>
  <li>Calculates average and assigns grades</li>
  <li>Analyzes class performance & subject averages</li>
  <li>Displays Top 3 students</li>
</ol>

<h2>📂 Project Structure</h2>
<pre>
main.py               → Main file to run the analytics
functions.py          → Calculation logic
students.csv          → Student dataset
README.md             → Project documentation
</pre>
