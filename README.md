# 📊 Student Performance Analytics System

Analyze student academic performance effortlessly using Python!
Turn your raw CSV marks into smart insights, grades, and topper lists.

---
### 🚀 Overview
This project uses *Python, Pandas and NumPy* to analyze student marks in real-time. By reading student data from a CSV file, it calculates total, average, grades and generates performance analytics automatically.

---
### ✨ Features
- 📚 Automatic CSV data loading
- 🧮 Total, Average & Grade calculation
- 🎯 Pass/Fail detection
- 📈 Class average, Highest & Lowest marks
- 📊 Subject-wise performance analysis
- 🏆 Top 3 performers list

---
### 🛠️ Tech Stack
- Python
- Pandas
- NumPy

---
### 🧩 How It Works
1. Reads student data from `students.csv`
2. Calculates total marks using functions
3. Calculates average and assigns grades
4. Analyzes class performance & subject averages
5. Displays Top 3 students

---
### 📁 Project Structure
Student-Performance-Analytics-System/
├── main.py -> Main file to run the analytics
├── functions.py -> Calculation logic
├── students.csv -> Student dataset
└── README.md -> Project documentation
---
### ▶️ Getting Started

#### 1. Install Dependencies
pip install pandas numpy
#### 2. Run the Project
python main.py
---
### 🎮 Controls
- 👉 Run `python main.py` to see analytics
- ⛔ Press Ctrl + C to exit
